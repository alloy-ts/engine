# Engine

`@alloy-ts/engine` is Alloy TS's embedded ECMAScript runtime, a growing subset
of ECMA-262 written in Rust and exposed to Node.js as a NAPI-RS addon.

```js
import { Engine } from "@alloy-ts/engine";

const context = new Engine().createContext();
context.eval("let x = 2; x * 21"); // 42
```

## Architecture

The crate has two layers with one boundary between them:

- **`src/runtime/`** is the language runtime: values, the string heap, Realms
  and environment records, the lexer, parser and evaluator, and the number
  and operation semantics. It is plain Rust with no napi or Node dependency
  and no `unsafe` code, so it is tested with `cargo test` alone and can be
  linked by other Rust crates (`alloy_engine::runtime`).
- **`src/engine.rs`** is the NAPI facade: the JavaScript `Engine` and
  `Context` classes. It is the only module that converts between host
  `napi_value`s and runtime values, and it rejects anything outside the
  supported primitives with a `TypeError`.

TypeScript declarations are generated by napi-rs from the Rust source at
build time; there is no handwritten `.d.ts`.

See [`docs/architecture.md`](docs/architecture.md),
[`docs/engine-plan.md`](docs/engine-plan.md) for the supported language
subset, [`docs/roadmap.md`](docs/roadmap.md) for the ownership and Node
compatibility milestones, [`docs/object-model.md`](docs/object-model.md) for
the CompactCell/object/collector target architecture, and [`docs/api`](docs/api)
for the JavaScript and Rust APIs.

## Command line

```sh
npx @alloy-ts/engine eval "5-888"    # prints -883
npx @alloy-ts/engine eval -          # read source from stdin
```

The `alloy-engine` binary evaluates a script with the NAPI `Engine`/`Context`
facade and prints the completion value. Parse or runtime errors are written to
stderr and the process exits non-zero. Pass `--help` for usage.

## Development

Requires Node.js, npm and a Rust toolchain.

```sh
npm ci            # install dependencies and configure the repository hooks
npm run build     # build the native addon and the package entry into dist/
npm run test      # Node tests against dist/, then cargo test
```

Rust-only checks:

```sh
cargo fmt --check
cargo check --all-targets
cargo test
cargo clippy --all-targets -- -D warnings
```
